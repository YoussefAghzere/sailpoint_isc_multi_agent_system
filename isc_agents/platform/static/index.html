Model budgets & options

Maximum orchestrator replies per plan (default 16). Specialists share a separate bounded allowance. More turns take longer; they do not increase the model context window.

Your model must support JSON schemas and have enough context for documents, tool results and output. Character budgets are not token counts.

NO CLOUD API ACCOUNT NEEDED

Start Qwen or Llama on your Mac

Install llama.cpp, download an instruction-tuned GGUF model compatible with your machine, and run it in a separate terminal:

brew install llama.cpp
llama-server -m /path/to/model.gguf --alias qwen --jinja \
  --host 127.0.0.1 --port 8080 --ctx-size 32768 --parallel 1

Keep that terminal running. Save a local profile with model alias qwen and URL http://127.0.0.1:8080/v1, then test its structured JSON output. The alias can point to either a Qwen or a Llama model.
